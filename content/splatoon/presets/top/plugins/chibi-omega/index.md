P1 / P3 のオメガを小さくするプラグインです。画面共有や録画、配信にも小さく映るので注意が必要です。

## 導入

1. `/xlsettings` コマンド → 試験的機能 → カスタムプラグインリポジトリに以下の URL を追加
2. `/xlplugins` コマンド → Chibi Omega をインストール

```
https://raw.githubusercontent.com/paissaheavyindustries/Dalamud-Repo/main/repo.json
```

Lemegeton と同じリポジトリなので、どちらか一方で追加すれば十分です。

## 設定

有効にしたフェーズでサイズが変更されます。ゾーンインまたはワイプ後に反映されます。
